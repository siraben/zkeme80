* Legacy Test Coverage [156/160]

Coverage of kernel Forth words by the on-demand test suite in
=src/bootstrap-flash4.fs=.  The suite runs from the main menu ("Run
the test suite"); every =T{ ... }T}= block increments the counters
that =REPORT-TESTS= paints on screen.  Rebuild and run headlessly
with:

: nix develop -c sh -c 'cd src && make build'
: tilem2 --headless --rom src/zkeme80.rom \
    --normal-speed \
    --macro debug/macros/run-test-suite.macro

Excludes words with special semantics used in the forth.scm stage
only (0BRANCH BRANCH 0JUMP JUMP), interpreter words (QUIT INTERPRET),
and I/O-hardware-bound words (key input, sprite drawing, EMIT, ...).
Those hardware paths need dedicated TilEm macro scenarios rather than
stack assertions in this tally.

Note: several entries below are Forth-layer words defined in
bootstrap-flash1.fs rather than kernel words; they are tested by the
same suite.

* Known gaps / future work

- The number parser now follows BASE (2 through 36), accepts alphabetic
  digits and an optional leading minus sign, and is covered in decimal
  and hexadecimal.  Overflow still wraps to the 16-bit cell width.
- TO and +TO parse the value name themselves (ANS style): write
  "5 TO TV1" / "2 +TO TV1".  Postfix "TV1 TO" executes the VALUE word
  first and silently corrupts the operation.
- EXPECT is driven by hardware keys.  Its cursor, full-buffer, and
  repeated-empty-line cases still need a dedicated headless TilEm macro;
  ACCEPT exposes the standard received-count contract but is not yet
  exercised by the stack-only suite.
- An uncaught THROW now resets the data stack and enters QUIT safely;
  error display remains deliberately minimal on the calculator screen.
- Interpreter internals excluded by design: QUIT INTERPRET BRANCH
  0BRANCH JUMP 0JUMP LIT (').
- The flash5 "shell" is a key-echo demo (no REPL yet), so interactive
  word probing under headless TilEm must go through the test suite or
  a temporary suite edit.
